# Worklog M2-S6: branding overlay and source offer (senior engineer)

## R1: the Source link covered the editor toolbar's "Attach file" (M2-S6-ADR10-01/-02)

### Approach
- Cause: `.notestead-source-link` is `position: fixed; left: 0; bottom: 0`, over the bottom-left control of the editor
  toolbar (narrow 390x844: (0,796) 52x48; wide 1280x800: (0,752) 48x48) and near the side menu's bottom buttons.
- Fix (`packages/web-build/overlay/notestead-overlay.css`, commit `67e04a3`): `body > #root { height: calc(100% - 18px); }`.
  The app root stops 18px above the bottom edge, so the link sits in a strip no upstream control occupies, in every
  state and viewport. The selector matches only `index.html` (`#root` is not in `closed.html`/`just-one-client.html`,
  where the link has nothing to cover). The link itself is unchanged, so M2-AC12-01 (keyboard reachable, name
  "Source", on all three pages) is unaffected. No upstream source is copied; this is our own CSS rule.
- No ADR deviation: ADR-0010's rule ("never covers upstream controls") is met by reserving space instead of by a
  corner that is only empty by luck.

### Artifact (no rebuild)
The change is CSS only, and the overlay never touches webpack outputs, so a full ~43 min arm64 rebuild is not needed.
The local artifact is the CI artifact of run 37285783648 (`web-bundle-v3.7.21`, built at `dc515fa`) with the new
overlay CSS swapped in and repackaged with the real tooling:

2. `cp packages/web-build/overlay/notestead-overlay.css <scratch>/dist/notestead-overlay.css` (after committing `67e04a3`).
3. `source.html` names the bundle's commit (the generator wrote `dc515fa...`); M2-AC12-02 compares it with the manifest's
   `notestead.commit`. First E2E run failed M2-AC12-02 for that reason (artifact inconsistency, not a product bug).
   Fixed in the artifact: `sed -i 's/dc515fa0ce39.../67e04a39838c.../g' <scratch>/dist/source.html` (3 occurrences, the
   commit in the tree/blob URLs). A real CI `web-bundle` run regenerates this file itself.
4. `corepack yarn workspace web-build verify <scratch>/dist` OK; `corepack yarn workspace web-build package <scratch>/dist --out ~/joplin-web-app-work/artifacts-m2s6`
