# Test plan: M1-S1 Monorepo scaffold and version pin

- **Story:** `docs/backlog/M1.md` § M1-S1 (M1-AC1 … M1-AC4). **ADRs:** 0005, 0009 (0007 for test rules).
- **Branch:** `feat/M1-S1-scaffold`. **Owner of this plan:** qa-specialist.
- **Runner:** Node built-in `node:test` (`tests/acceptance/m1-s1/*.test.mts`), chosen because the scaffold (yarn, Jest) does not exist yet; see `docs/testing/strategy.md` §3. The suite treats the repo as a black box and calls `corepack yarn …` exactly as a user would.

## How to run
```sh
node --test --test-concurrency=1 --test-reporter=spec 'tests/acceptance/m1-s1/*.test.mts'
# optional: avoid the network for M1-AC4 by pointing at a local clone that contains web.commit
JOPLIN_UPSTREAM_DIR=~/joplin-web-app-work/upstream-joplin node --test --test-concurrency=1 'tests/acceptance/m1-s1/*.test.mts'
```
Every command's stdout/stderr, exit code and duration is written to `test-results/acceptance/m1-s1/<test-label>.log` (gitignored, redacted).

## Command contracts (binding for the implementation)
| Command | Contract |
|---|---|
| `corepack yarn install --immutable` | Exits 0 on a clean checkout: `yarn.lock` is committed and consistent. |
| `corepack yarn lint` | eslint **and** `tsc --noEmit` over `packages/**` and `tests/**`. Exits non-zero on any finding. The eslint flat config enables `jest/no-focused-tests` and `jest/no-disabled-tests` for `**/*.test.ts` (in packages and in `tests/`), `playwright/no-skipped-test` for `tests/e2e/**/*.spec.ts`, and bans `page.waitForTimeout` in tests via `no-restricted-syntax` (or `no-restricted-properties` / `playwright/no-wait-for-timeout`). Must report rule IDs with file paths (eslint's default `stylish` or any formatter printing path + rule ID). Type errors must surface as `TS<code>` with the file path; if eslint and tsc are chained with `&&`, a type-error-only file must still reach tsc (it does, as long as eslint passes on it). Must also type-check the acceptance suite: `tsc -p tests/acceptance/tsconfig.json` (needs `@types/node`, TypeScript ≥ 5.8 for `erasableSyntaxOnly`). Lint must not dirty the git tree (caches gitignored). |
| `corepack yarn test` | Jest unit + integration for every workspace. Prints Jest's `PASS <path>` line per test file (default reporter or equivalent). Must **not** run `tests/acceptance/**` (it would recurse); Jest's `testMatch` must not collect `*.mts` acceptance files or `tests/fixtures/**`. |
| `corepack yarn playwright --version` | Prints `Version 1.x.y` (Playwright wired). Playwright's `testDir` is `tests/e2e`. |
| `corepack yarn check:pin [--pin <file>] [--lockfile <file>]` | Defaults: `upstream/joplin-version.json` and the root `yarn.lock`. Validates the pin (below) and the lockfile against it. Exit 0 when valid; non-zero otherwise. Every problem is reported with the **dotted field path** (`web.commit`, `cli.version`, `server.tag`, `syncVersion`, `minor`, …) or, for lockfile problems, the **package name and the offending resolved version** (`@joplin/lib … 3.8.0`). An unreadable/non-JSON pin names the file. Paths in tests are absolute. |
| `corepack yarn check:no-upstream-copy [--root <dir>] [--upstream <git-dir>] [--pin <file>]` | Scans the git-**tracked** files of `--root` (default: repo root) that are ≥ 1 KiB, and fails if any is byte-identical to a file in the upstream tree at the pin's `web.commit` (the pin is read from **this** repo unless `--pin` is given; `--root` only selects the scanned tree). `--upstream` is a local clone (full, shallow or partial) containing `web.commit`; without it the script obtains a sparse clone itself (cache it per commit; CI and the Pi use the same code path). Untracked/ignored files (e.g. `node_modules/`) are never scanned. On failure it names each offending file by its path relative to `--root` (absolute is fine too) and does not name clean files. Hint (non-binding): comparing `git hash-object` of our files with the blob IDs from `git ls-tree -r -l <commit>` needs no upstream blobs at all, so a `--filter=blob:none --depth 1` clone suffices. |

**Pin schema (M1-AC2), all fields required:** `minor` (`^\d+\.\d+$`), `web.repo`, `web.branch`, `web.tag`, `web.commit` (exactly 40 lowercase hex), `cli.npm`, `cli.version` (exact semver `X.Y.Z`, no range, and inside `minor` per ADR-0005 §2), `server.image`, `server.tag` (non-empty string), `syncVersion` (integer).

**Lockfile rule (M1-AC3):** the entry for the package named exactly `joplin` must exist and resolve to `cli.version`; every **lockstep** `@joplin/*` package resolves to `<minor>.x`. Lockstep = every `@joplin/*` except the independently versioned forks `@joplin/fork-*` and `@joplin/turndown*` (see Interpretation 1). Packages that merely start with `joplin` (e.g. `joplin-turndown-plugin-gfm`) are not `joplin`.

## Interpretations and findings (for the architect / orchestrator)
1. **M1-AC3 wording vs reality.** "Every `@joplin/*` package to the pin's minor" cannot hold literally: `@joplin/lib@3.7.1` depends on independently versioned forks (`@joplin/fork-htmlparser2@^4.1.64`, `@joplin/fork-sax@^1.2.68`, `@joplin/fork-uslug@^2.0.7`, `@joplin/turndown@^4.0.86`, `@joplin/turndown-plugin-gfm@^1.0.68`; verified at `cli-v3.7.1`). The tests apply the minor rule to all `@joplin/*` **except** `@joplin/fork-*` and `@joplin/turndown*` (fail-closed: a new lockstep package is checked by default). ADR-0005 itself only requires `@joplin/lib`. Suggest the architect amends the AC wording.
2. **The real lockfile must contain `joplin@3.7.1` already in M1-S1** (T11, T01d), because M1-AC3 requires `yarn.lock` to resolve `joplin`. ADR-0005 §1 puts `"joplin": "3.7.1"` (exact) in `packages/headless/package.json`; a minimal `packages/headless` manifest is enough here (the supervisor is M1-S5).
3. **Lint rules beyond the AC NEG** (T06b–T06e, T07) verify ADR-0009's decisions (`jest/no-disabled-tests`, `playwright/no-skipped-test`, the `waitForTimeout` ban, `tsc --noEmit` inside lint), which ADR-0009 lists M1-AC1 as verifying. They share one lint run with the AC NEG (T07 needs a second run so tsc is reached).
4. **`cli.version` outside `minor`** (`cli.version--outside-minor.json`) is derived from ADR-0005 §2 (same-minor skew policy), not from the AC text.
5. **The license-header part of `check:no-upstream-copy`** (ADR-0009: "or if a file carries upstream's license header with upstream's copyright line") is not in M1-AC4 and not tested here; proposed for a later story.

## Requirements on the implementation (no production seams needed)
- Root `package.json`: `private: true`, `license: AGPL-3.0-or-later`, `packageManager: yarn@4.x.y`, `workspaces` includes `packages/*`, scripts `lint`, `test`, `check:pin`, `check:no-upstream-copy`. Each `packages/*/package.json` is `AGPL-3.0-or-later`. Tooling declared somewhere in the manifests: `typescript`, `eslint`, `jest`, `@playwright/test`, `eslint-plugin-jest`, `eslint-plugin-playwright`, `@types/node`.
- `.yarnrc.yml`: `nodeLinker: node-modules`, `npmMinimalAgeGate` set.
- At least one workspace has a `src/` directory (the lint NEG fixtures are placed in `<first such package>/src/__lint_neg__/` and removed afterwards); its tsconfig must cover `src/**`.
- Do not gitignore or eslint-ignore `__lint_neg__` paths, `tests/unit/**` or `tests/e2e/**`.
- Optional root script for convenience: `"test:acceptance": "node --test --test-concurrency=1 --test-reporter=spec 'tests/acceptance/**/*.test.mts'"` (never part of `test`).

## Out of scope
- `syncVersion` equality with the pinned web ref and the installed `@joplin/lib` (M3-AC9, M6-AC2).
- `check:licenses` (ADR-0009) and `check:workflows` (M1-AC8).
- x64 runs: CI does not exist until M1-S3; the suite is CI-ready (no host-specific paths except the optional local upstream clone).
