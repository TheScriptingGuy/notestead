# Joplin Web App (unofficial)

A self-hosted companion stack **for Joplin**, built from existing upstream Joplin components:

- **Web UI.** Upstream's own web build of the Joplin app, served from your server and syncing with your self-hosted Joplin Server. Plugins work if they support mobile.
- **Headless Data API.** The same REST API the Joplin desktop app exposes, running headless and kept in sync with your Joplin Server.
- **MCP server.** AI assistants can manage notes, to-dos, alarms, notebooks and tags.

Runs on x64 and arm64 (Raspberry Pi included).

> **Status:** early planning. See [`docs/backlog/STATUS.md`](docs/backlog/STATUS.md).
